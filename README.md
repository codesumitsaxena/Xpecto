# Xpecto IT Solutions - Modern Corporate Web Application

A high-performance, pixel-perfect clone and redesign of **[Xpecto IT Solutions](https://www.xpectoitsolutions.com/)** built with **React 19**, **Vite**, **Tailwind CSS**, and **Lucide Icons**.

---

## 🚀 Live Demo & Repository
- **GitHub Repository:** [https://github.com/codesumitsaxena/Xpecto](https://github.com/codesumitsaxena/Xpecto)
- **Deployment Platform:** Vercel

---

## 🌟 Key Features

- 🌓 **Instant Dark & Light Theme Toggle:**
  - Persisted state via `localStorage`.
  - Class-based theme switching with `@custom-variant dark`.
  - Seamless smooth CSS color transitions.

- 📱 **100% Fully Responsive Design:**
  - Optimized for mobile, tablet, laptop, and ultra-wide screens.
  - Interactive slide-out mobile drawer menu.

- 💫 **Authentic Interactive Navigation:**
  - **Mega-Menu for Services** (Category tabs with dynamic cards).
  - **Split Technology Menu** (UI/UX, Frontend, Backend, Cloud, Frameworks).
  - **Industry Verticals** (Finance, eCommerce, Manufacturing, Media, Education).
  - **About Us Dropdown** (History, Testimonials, Methodology, Clients).

- ⚡ **Continuous Auto-Scrolling Client Carousel:**
  - High-resolution client brand strip (`Penam`, `Pikeazy`, `SD Carbons`, `VisionSafe`, `Disposafe`, `Vijaya Enterprises`, `KG Group`, `Infomerics`, etc.) with seamless infinite marquee animation.

- 💎 **Premium Modern Solution Cards:**
  - Glassmorphic card styling with customized gradient accent tops.
  - Interactive hover elevations, subtle glows, and SVG badges.

- 💼 **Service Pages:**
  - **Custom Application Development:** `/services/custom-application`
  - **Web Application Development:** `/services/web-application`
  - Client testimonial integration (Dean Roberts - VisionSafe), metrics counters, and consultation request forms.

## 📦 Getting Started

### Prerequisites
- Node.js (v18 or higher recommended)
- npm or yarn

### Installation

1. **Clone the repository:**
   ```bash
   git clone https://github.com/codesumitsaxena/Xpecto.git
   cd Xpecto
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Start the development server:**
   ```bash
   npm run dev
   ```
   Open `http://localhost:5174` (or your Vite local port) in your browser.

4. **Build for production:**
   ```bash
   npm run build
   ```

---

## 🌐 Deploy to Vercel

### Option 1: Via Vercel CLI
```bash
npm i -g vercel
vercel
```

### Option 2: Via Vercel Dashboard
1. Go to [vercel.com](https://vercel.com) and sign in.
2. Click **"Add New"** > **"Project"**.
3. Import your GitHub repository: `codesumitsaxena/Xpecto`.
4. Keep the default settings (Framework Preset: **Vite**).
5. Click **Deploy**.
